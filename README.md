# ESP32 + LCD 16×2 + Keypad 3×4 ผ่าน PCF8574

โปรเจกต์นี้ต่อ **จอ LCD 1602** และ **คีย์แพดเมมเบรน 3×4** เข้า ESP32 โดยใช้ **PCF8574 เป็น I/O expander บนบัส I2C** เพื่อประหยัดพิน GPIO

ต้องใช้ **PCF8574 สองตัว** บนบัสเดียวกัน เพราะ LCD โหมด 4 บิตกิน 7–8 พิน และคีย์แพด 3×4 กิน 7 พิน รวมเกิน 8 พินของชิปเดียว

| อุปกรณ์ | ชิป | Address แนะนำ | หน้าที่ |
|---|---|---|---|
| โมดูล LCD 1602 I2C | PCF8574 บน backpack | `0x27` (หรือ `0x3F`) | ขับ RS, E, D4–D7, backlight |
| โมดูล PCF8574 แยก | PCF8574 | `0x20` (A0=A1=A2 ลง GND) | สแกนแถว/คอลัมน์ของคีย์แพด |

```
ESP32 DevKit
  3V3 ──┬── VCC (PCF8574 คีย์แพด)     ← แนะนำ 3.3V
        └── (ทางเลือก) VCC LCD I2C    ← ถ้าจอไม่ติด ลอง 5V ดูหัวข้อแรงดันไฟ
  5V  ──── VCC โมดูล LCD I2C          ← ใช้บ่อยเพื่อ contrast/backlight
  GND ──┬── GND LCD I2C
        └── GND PCF8574 คีย์แพด
 GPIO21 ── SDA ของทั้งสองโมดูล (บัสร่วม)
 GPIO22 ── SCL ของทั้งสองโมดูล (บัสร่วม)
```

## อุปกรณ์

- ESP32 DevKit (30 พิน หรือ 38 พิน)
- LCD 16×2 **แบบมีโมดูล I2C (PCF8574 backpack)** — ถ้าเป็นจอเปล่า 4 บิต ต้องมี backpack หรือต่อผ่าน PCF8574 อีกตัว
- คีย์แพดเมมเบรน **3×4** (7 ขา)
- โมดูล **PCF8574** (หรือ PCF8574A) สำหรับคีย์แพด
- สายจัมเปอร์, ขนมปังบอร์ด
- (แนะนำ) ตัวต้านทาน 4.7 kΩ สองตัว สำหรับ pull-up SDA/SCL ถ้าโมดูลไม่มีให้มา

## 1) บัส I2C จาก ESP32

พิน I2C ค่าเริ่มต้นของ ESP32:

| ESP32 | สัญญาณ | ไปที่ |
|---|---|---|
| GPIO **21** | SDA | SDA ของ LCD I2C **และ** SDA ของ PCF8574 คีย์แพด |
| GPIO **22** | SCL | SCL ของ LCD I2C **และ** SCL ของ PCF8574 คีย์แพด |
| GND | GND | GND ของทั้งสองโมดูล (ร่วมกราวด์ทุกชิ้น) |

โมดูลทั้งสองต่อ **ขนานบนบัสเดียวกัน** ต่างกันที่ address เท่านั้น

ถ้าโมดูลไม่มี pull-up ให้ต่อ 4.7 kΩ จาก SDA ไป 3.3V และจาก SCL ไป 3.3V

## 2) แรงดันไฟ (สำคัญกับ ESP32)

GPIO ของ ESP32 **ไม่ทน 5V**

- **PCF8574 คีย์แพด:** จ่าย **3.3V** จากขา `3V3` ของ ESP32
- **LCD I2C:** จอ HD44780 มักสว่าง/contrast ดีที่ 5V แต่ถ้าจ่าย 5V ให้ backpack พิน SDA/SCL จะถูกดึงขึ้น 5V ผ่านตัวต้านทาน pull-up บนโมดูล

แนวทางที่ปลอดภัย:

1. จ่าย LCD I2C ที่ **3.3V** ก่อน ถ้าตัวอักษรจาง ให้หมุนโพเทนชิโอมิเตอร์หลังโมดูล
2. ถ้าต้องใช้ 5V กับจอ: **ถอดหรือยกตัวต้านทาน pull-up บนโมดูล LCD** แล้วใช้ pull-up ไปที่ 3.3V แทน (หรือใช้เลเวลชิฟเตอร์)

สำหรับทดลองสั้น ๆ หลายคนจ่าย LCD ที่ 5V โดยตรง — ใช้งานได้บ่อยแต่มีความเสี่ยงต่อพิน ESP32

## 3) ตั้งค่า address ของ PCF8574 คีย์แพด

บนโมดูลมีจัมเปอร์ **A0 A1 A2**

| ชิป | A0 | A1 | A2 | Address 7-bit |
|---|---|---|---|---|
| **PCF8574** | GND | GND | GND | **`0x20`** ← ค่าในโค้ด |
| PCF8574 | VCC | GND | GND | `0x21` |
| **PCF8574A** | GND | GND | GND | **`0x38`** |

โมดูล LCD I2C มักเป็น `0x27` (A0–A2 ไม่บัดกรี = ดึงขึ้น) หรือ `0x3F` ถ้าใช้ PCF8574A

ห้ามให้สองตัวใช้ address ซ้ำ ถ้าสแกนแล้วเจอแค่ตัวเดียว แปลว่าชนกันหรือต่อไม่ครบ

เปิด Serial Monitor 115200 baud ตอนบูต จะมี **I2C scan** บอก address ที่พบ จากนั้นแก้ค่าในสเก็ตช์ถ้าไม่ตรง:

```cpp
static const uint8_t LCD_ADDR = 0x27;
static const uint8_t KEYPAD_ADDR = 0x20;
```

## 4) ต่อคีย์แพด 3×4 เข้า PCF8574

คีย์แพด 3×4 มี **7 ขา** โดยทั่วไปเรียงจากซ้ายไปขวา (ฝั่งขาสาย ปุ่มหงายขึ้น):

```
ขาคีย์แพด:  1     2     3     4     5     6     7
หน้าที่:     Row1  Row2  Row3  Row4  Col1  Col2  Col3
ปุ่มในแถว:  123   456   789   *0#   147*  2580  369#
                 P0    P1    P2    P3    P4    P5    P6   ของ PCF8574
```

| PCF8574 | คีย์แพด | หมายเหตุ |
|---|---|---|
| P0 | ขา 1 (Row 1) | ปุ่ม 1 2 3 |
| P1 | ขา 2 (Row 2) | ปุ่ม 4 5 6 |
| P2 | ขา 3 (Row 3) | ปุ่ม 7 8 9 |
| P3 | ขา 4 (Row 4) | ปุ่ม * 0 # |
| P4 | ขา 5 (Col 1) | ปุ่ม 1 4 7 * |
| P5 | ขา 6 (Col 2) | ปุ่ม 2 5 8 0 |
| P6 | ขา 7 (Col 3) | ปุ่ม 3 6 9 # |
| P7 | ไม่ต่อ | สำรอง |
| VCC | 3.3V | |
| GND | GND | |
| SDA | GPIO 21 | |
| SCL | GPIO 22 | |

ถ้ากดปุ่มแล้วได้คนละตัว ให้สลับแถว/คอลัมน์ หรือแก้ตาราง `kMap` ในโค้ด — ผังขาคีย์แพดแต่ละยี่ห้อไม่เหมือนกันทุกตัว วัดด้วยมัลติมิเตอร์โหมดต่อเนื่องได้: กดปุ่ม 1 แล้วหาสองขาที่ช็อตกัน คือ Row1 กับ Col1

## 5) ต่อ LCD 16×2 (โมดูล I2C)

โมดูล LCD I2C มี 4 ขา:

| LCD I2C | ESP32 |
|---|---|
| GND | GND |
| VCC | 5V หรือ 3.3V (ดูหัวข้อแรงดันไฟ) |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

ไม่ต้องต่อพิน D0–D7 ของจอเอง backpack จัดการให้แล้ว

หมุนโพเทนชิโอมิเตอร์สีน้ำเงินด้านหลังโมดูลถ้าจอมี backlight แต่ไม่มีตัวอักษร (contrast)

## วิธีใช้โค้ด

ไฟล์หลัก: [`esp32_lcd_keypad/esp32_lcd_keypad.ino`](esp32_lcd_keypad/esp32_lcd_keypad.ino)

ไม่ต้องติดตั้งไลบรารีเพิ่ม (ใช้แค่ `Wire.h`)

### Arduino IDE

1. ติดตั้งบอร์ด **esp32** โดย Espressif (`esp32:esp32`)
2. เลือกบอร์ด เช่น *ESP32 Dev Module*
3. เปิดโฟลเดอร์ `esp32_lcd_keypad` แล้วอัปโหลด
4. Serial Monitor ความเร็ว **115200**

### PlatformIO

```bash
pio run -t upload
pio device monitor
```

### พฤติกรรมตัวอย่าง

- บรรทัดบนจอ: สถานะ
- กดตัวเลข: สะสมข้อความที่บรรทัดล่าง
- กด `*` : ล้างข้อความ
- กด `#` : ยืนยันค่าที่พิมพ์

## แก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| I2C scan ไม่เจออะไร | สลับ SDA/SCL, ไม่ร่วม GND, ไม่มีไฟ, ลืม pull-up |
| เจอแค่ LCD ไม่เจอคีย์แพด | จัมเปอร์ A0–A2, ชิปเป็น PCF8574A (ใช้ 0x38), สาย SDA/SCL ของโมดูลหลุด |
| จอสว่างแต่ไม่มีตัวอักษร | หมุนคอนทราสต์, address ไม่ใช่ 0x27 ลอง 0x3F, จ่าย 5V ให้จอ |
| กดปุ่มแล้วได้คนละตัว | สลับแถว/คอลัมน์ หรือแก้ `kMap` |
| กดแล้วไม่ขึ้นเลย | P4–P6 ต้องเป็นคอลัมน์, ตรวจว่าโมดูลเป็น PCF8574 ไม่ใช่ MCP23008 |
| รีเซ็ตเอง/แฮงก์ | บัส 5V เข้า GPIO, สาย I2C ยาวไม่มี pull-up, ไฟ 3.3V ไม่พอ |

ถ้าต้องย้ายพิน I2C แก้สองค่านี้:

```cpp
static const int PIN_SDA = 21;
static const int PIN_SCL = 22;
```
