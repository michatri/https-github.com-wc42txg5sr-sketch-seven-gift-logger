# ESP32 6-digit keypad

Arduino sketch for an ESP32 with a 16x2 I2C LCD and a 4x3 keypad.

Copy [esp32-6digit-keypad/esp32-6digit-keypad.ino](esp32-6digit-keypad/esp32-6digit-keypad.ino) into Arduino IDE. It is a single file. Wiring notes: [esp32-6digit-keypad/README.md](esp32-6digit-keypad/README.md).

- Enter up to **6 digits**
- `*` deletes the last digit
- `#` confirms the value
