# ESP32 + LCD 16×2 + Keypad 3×4 ผ่าน I2C

สเก็ตช์นี้ใช้ไลบรารีมาตรฐานสองตัวบนบัส I2C เดียวกัน:

| ไลบรารี | ทำอะไร | Address |
|---|---|---|
| `LiquidCrystal_I2C` | ขับจอ 16×2 ผ่าน backpack PCF8574 | `0x27` (หรือ `0x3F`) |
| `Keypad_I2C` (Joe Young) | สแกนคีย์แพด 3×4 ผ่าน PCF8574 อีกตัว | `0x20` |

ไฟล์อัปโหลด: [`esp32_lcd_keypad_i2c/esp32_lcd_keypad_i2c.ino`](esp32_lcd_keypad_i2c/esp32_lcd_keypad_i2c.ino)

---

## สรุปการทำงานของโค้ด

### ไลบรารีสามตัว

```cpp
#include <Wire.h>                 // บัส I2C ของ ESP32
#include <LiquidCrystal_I2C.h>    // จอ HD44780 ผ่าน PCF8574 backpack
#include <Keypad.h>               // สแกนเมทริกซ์ + debounce (ฐานของ Keypad_I2C)
#include "Keypad_I2C.h"           // แทน GPIO ด้วยพิน P0–P7 ของ PCF8574
```

- `Wire` คือบัสจริง สายแค่ **SDA + SCL**
- `LiquidCrystal_I2C` แปลงคำสั่งจอ (`setCursor`, `print`, `backlight`) เป็นไบต์ส่งไปที่ backpack
- `Keypad_I2C` สืบทอดจาก `Keypad` แต่ `pin_write` / `pin_read` ไปที่ PCF8574 แทน GPIO ของ ESP32

ต้องใช้ **PCF8574 สองตัว** เพราะจอโหมด 4 บิตกินประมาณ 8 พิน และคีย์แพด 3×4 กิน 7 พิน รวมเกิน 8 พินของชิปเดียว

### ทำไม address ต้องคนละค่า

บนบัส I2C แต่ละชิปต้องมี address ไม่ซ้ำ

```cpp
LiquidCrystal_I2C lcd(0x27, 16, 2);
#define KEYPAD_I2C_ADDR 0x20
```

| ชิป | จัมเปอร์ A0 A1 A2 | Address |
|---|---|---|
| LCD backpack (PCF8574) | มักลอย/ดึงขึ้น | `0x27` |
| LCD backpack (PCF8574A) | ลอย | `0x3F` |
| PCF8574 คีย์แพด | ต่อ GND ทั้งสามจุด | `0x20` |
| PCF8574A คีย์แพด | ต่อ GND ทั้งสามจุด | `0x38` |

ถ้าสองตัวชน address สแกนจะเจอแค่ตัวเดียว

### แมปคีย์แพดเข้า PCF8574

```
P0 P1 P2 P3   = แถว 1 2 3 4     →  123 / 456 / 789 / *0#
P4 P5 P6      = คอลัมน์ 1 2 3   →  147* / 2580 / 369#
P7            ไม่ใช้
```

`getKey()` ของไลบรารี Keypad ดึงแถวลงทีละแถว แล้วดูว่าคอลัมน์ไหนเป็น 0 — PCF8574 เป็นพินกึ่งสองทิศทาง: เขียน `1` = อินพุตมี pull-up อ่อน, เขียน `0` = เอาต์พุตต่ำ ดังนั้นแถวที่ไม่ได้สแกนต้องปล่อยเป็น 1

### `setup()` ลำดับที่ถูก

1. `Wire.begin(21, 22)` — ล็อกพิน I2C ของ ESP32 (ค่าเริ่มต้นคือ 21/22 อยู่แล้ว แต่ระบุชัดไว้)
2. สแกนบัส ดูว่าเจอ `0x27` กับ `0x20` หรือไม่
3. `lcd.init()` + `lcd.backlight()` — บางเวอร์ชันของ `init()` เรียก `Wire.begin()` เองแบบไม่ระบุพิน จึงเรียก `Wire.begin(21, 22)` อีกครั้งหลังจอพร้อม
4. `customKeypad.begin()` — เขียน `0xFF` เข้า PCF8574 คีย์แพด (ทุกพินเป็นอินพุต/สูง) **ต้องอยู่หลัง Wire พร้อมแล้ว**

### `loop()`

```cpp
char key = customKeypad.getKey();
if (key) { ... }
```

`getKey()` คืนค่าครั้งเดียวตอนกดลง (มี debounce ในไลบรารี) ไม่ใช่ทุกครั้งที่กดค้าง — เหมาะกับพิมพ์ตัวอักษรทีละปุ่ม

บรรทัดล่างจอแสดง `Key Pressed: X` (15 ตัวอักษร อยู่ใน 16 คอลัมน์) ช่องว่างท้ายใช้ลบตัวเก่าถ้ากดปุ่มใหม่

## การต่อสาย

```
ESP32 DevKit
  3V3 ── PCF8574 คีย์แพด VCC     ← ใช้ 3.3V (GPIO ESP32 ไม่ทน 5V)
  5V  ── LCD I2C VCC             ← จอสว่าง/contrast ดีที่ 5V
  GND ── GND ของทั้งสองโมดูล
 GPIO21 ── SDA ของทั้งสองโมดูล
 GPIO22 ── SCL ของทั้งสองโมดูล
```

ถ้าโมดูลไม่มี pull-up ให้ต่อ 4.7 kΩ จาก SDA ไป 3.3V และจาก SCL ไป 3.3V

เมื่อจ่ายจอที่ 5V พิน SDA/SCL ของ backpack อาจถูกดึงขึ้น 5V ผ่านตัวต้านทานบนโมดูล — สำหรับทดลองสั้น ๆ หลายคนทำแบบนี้ได้ แต่ทางที่ปลอดภัยกว่าคือถอด pull-up บนโมดูล LCD แล้วดึงขึ้นที่ 3.3V

### คีย์แพด 3×4 → PCF8574

ขาคีย์แพดทั่วไป (สายออกด้านบน ปุ่มหงาย):

| ขาคีย์แพด | หน้าที่ | PCF8574 |
|---|---|---|
| 1 | Row 1 (1 2 3) | P0 |
| 2 | Row 2 (4 5 6) | P1 |
| 3 | Row 3 (7 8 9) | P2 |
| 4 | Row 4 (* 0 #) | P3 |
| 5 | Col 1 (1 4 7 *) | P4 |
| 6 | Col 2 (2 5 8 0) | P5 |
| 7 | Col 3 (3 6 9 #) | P6 |

ยี่ห้อคีย์แพดเรียงขาไม่เหมือนกันทุกตัว ถ้ากดแล้วได้คนละตัว ให้สลับแถว/คอลัมน์ หรือแก้ตาราง `keys` — วัดด้วยมัลติมิเตอร์โหมดต่อเนื่อง: กดปุ่ม `1` แล้วหาสองขาที่ช็อตกัน คือ Row1 กับ Col1

## อัปโหลด

### Arduino IDE

1. ติดตั้งบอร์ด **esp32** โดย Espressif
2. Library Manager: **LiquidCrystal I2C** (Frank de Brabander) และ **Keypad** (Mark Stanley)
3. เปิดโฟลเดอร์ `esp32_lcd_keypad_i2c` แล้วอัปโหลด (ไฟล์ `Keypad_I2C.h` / `.cpp` อยู่ในโฟลเดอร์สเก็ตช์แล้ว ไม่ต้องติดตั้งแยก)
4. Serial Monitor **115200** — ตอนบูตมี I2C scan

### PlatformIO

```bash
pio run -t upload
pio device monitor
```

## แก้ปัญหา

| อาการ | สิ่งที่ตรวจ |
|---|---|
| I2C scan ไม่เจออะไร | สลับ SDA/SCL, ไม่ร่วม GND, ไม่มีไฟ |
| เจอแค่จอ ไม่เจอคีย์แพด | จัมเปอร์ A0–A2, ชิปเป็น PCF8574A (`0x38`) |
| จอสว่างแต่ไม่มีตัวอักษร | หมุนคอนทราสต์หลังโมดูล, ลอง address `0x3F` |
| กดแล้วได้คนละตัว | แก้ `keys` / สลับ `rowPins` กับ `colPins` |
| กดแล้วไม่ขึ้น | P4–P6 ต้องเป็นคอลัมน์, `begin()` ต้องหลัง `Wire.begin` |
| คอมไพล์ไม่ผ่าน `Keypad_I2C` | ติดตั้งไลบรารี **Keypad** ด้วย ไม่ใช่แค่ไฟล์ในโฟลเดอร์นี้ |

ถ้าต้องย้ายพิน I2C แก้ `Wire.begin(21, 22)` ทั้งสองจุดใน `setup()`
