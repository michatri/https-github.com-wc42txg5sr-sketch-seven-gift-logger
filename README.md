# ESP32 6-digit keypad

Arduino sketch for an ESP32 with a 16x2 I2C LCD and a 4x3 keypad.

Copy the keypad sketch into Arduino IDE. Wiring: [esp32-6digit-keypad/README.md](esp32-6digit-keypad/README.md).

The ESP32-S3 HUB75 board shows the same numbers on a P4 64x32 panel. See [esp32s3-hub75-p4/README.md](esp32s3-hub75-p4/README.md).

- Enter up to **6 digits** per number
- `*` clears the screen
- `#` inserts a space so the next number can be typed
