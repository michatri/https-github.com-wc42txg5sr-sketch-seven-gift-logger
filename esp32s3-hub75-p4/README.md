# ESP32-S3 HUB75 — จอ P4 64x32

รับตัวเลขจากบอร์ดคีย์แพด แล้วแสดงบนจอ LED P4 indoor 256x125mm (64x32 dots)

## ของที่ต้องมี

- บอร์ด ESP-HUB75 ที่ใช้ ESP32-S3
- จอ P4 indoor HUB75 64x32
- สายแพ HUB75 ต่อเข้าช่อง **IN** ของจอ
- ไฟ **5V** สำหรับจอแยกจาก USB (แนะนำ 5V 3A ขึ้นไป) GND ร่วมกับบอร์ด

## ไลบรารีใน Arduino IDE

Sketch → Include Library → Manage Libraries

1. `ESP32 HUB75 LED MATRIX PANEL DMA Display`
2. `Adafruit GFX Library`

บอร์ด: **ESP32S3 Dev Module**
Port: COM ของบอร์ด S3 (คนละพอร์ตกับคีย์แพด COM3)

## การทำงาน

1. อัปโหลด `esp32-6digit-keypad.ino` เข้า ESP32 คีย์แพด ที่ COM3
2. อัปโหลดไฟล์นี้เข้า ESP32-S3
3. กดตัวเลขบนคีย์แพด จอ P4 จะขึ้นตัวเลขตาม
4. `*` ล้างจอทั้ง LCD และจอ P4
5. `#` เว้นวรรค แล้วพิมพ์ชุดถัดไป

ส่งข้อมูลด้วย ESP-NOW ไม่ต้องเดินสายข้อมูลระหว่างสองบอร์ด แค่เปิดเครื่องทั้งคู่

## ขา HUB75 บน ESP32-S3

ค่าเริ่มต้นตามไลบรารี ESP32-S3 ถ้าจอไม่ขึ้นหรือสีเพี้ยน ให้แก้ขาในไฟล์ `.ino` ให้ตรงบอร์ด ESP-HUB75 ของคุณ

| สัญญาณ | GPIO |
|---------|------|
| R1 | 4 |
| G1 | 5 |
| B1 | 6 |
| R2 | 7 |
| G2 | 15 |
| B2 | 16 |
| A | 18 |
| B | 8 |
| C | 3 |
| D | 42 |
| E | ไม่ใช้ (จอ 64x32) |
| LAT | 40 |
| OE | 2 |
| CLK | 41 |

## ไฟจอ

อย่าจ่ายไฟจอ P4 จาก USB ของ ESP32 จอ 64x32 ใช้กระแสสูง ต่อ 5V ที่ขั้วไฟของแผง LED โดยตรง และต่อ GND ร่วมกับบอร์ด
