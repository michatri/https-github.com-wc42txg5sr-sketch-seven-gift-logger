# ESP32 — กดตัวเลขสูงสุด 6 หลัก

โปรแกรมสำหรับ **ESP32 + จอ LCD 16x2 (I2C) + คีย์แพด 4x3**

## ถ้ายังไม่เห็นอะไรเลย

การต่อสายอย่างเดียวจอจะยังว่าง ต้องอัปโหลดโปรแกรมก่อน

1. คัดลอกไฟล์ `esp32-6digit-keypad.ino` ทั้งไฟล์ไปวางใน Arduino IDE ได้เลย (เป็นไฟล์เดียว ไม่ต้องมีไฟล์อื่น)
2. ติดตั้งบอร์ด: **Tools → Board → Boards Manager** ค้นหา `esp32` โดย Espressif แล้วติดตั้ง
3. **ไม่ต้องติดตั้งไลบรารีเพิ่ม** และไม่ต้องมีไฟล์ `DigitInput.h` แล้ว
4. เลือกบอร์ด **ESP32 Dev Module** และพอร์ต COM ของบอร์ด
5. กด **Upload** แล้วเปิด **Serial Monitor ที่ 115200**
6. กดปุ่ม **EN** บนบอร์ดหนึ่งครั้ง

สัญญาณว่าโปรแกรมทำงานแล้ว:
- ไฟ LED บนบอร์ด ESP32 **กระพริบ** (GPIO 2)
- Serial มีข้อความ `ESP32 keypad start`
- จอขึ้น `HELLO ESP32` แล้วตามด้วย `Enter number`

ถ้า LED กระพริบแต่จอว่าง:
- หมุนสกรูสีน้ำเงินด้านหลังจอ (ปรับความคม)
- นับสายจอ: **4 เส้น = I2C** ต้องต่อ `SDA→21`, `SCL→22`, `VCC`, `GND`
- ดู Serial ว่าเจอ `found` หรือไม่ ถ้าขึ้น `no I2C device` แปลว่าสายจอยังไม่ถึงบอร์ด

ถ้า LED ไม่กระพริบ:
- อัปโหลดยังไม่สำเร็จ ดูข้อความสีแดงใน Arduino IDE
- เลือกพอร์ต COM ใหม่ แล้วกดปุ่ม **BOOT** ค้างขณะเริ่ม Upload ถ้าบอร์ดขึ้น `Connecting...`

## อัปโหลดไม่ติด (No serial data received)

Error นี้แปลว่าบอร์ดยังไม่เข้าโหมดแฟลช ไม่เกี่ยวกับโค้ดโปรแกรม

1. ถอดคีย์แพดและจอออกทั้งหมด เหลือแค่สาย USB
2. ปิด Serial Monitor และโปรแกรมอื่นที่เปิด COM อยู่
3. ถอดสาย USB แล้วเสียบใหม่ ดูที่ **Tools → Port** ว่ามี COM **ใหม่** โผล่ไหม
   - อย่าเลือก `COM1` ถ้าไม่ใช่พอร์ตที่เพิ่งโผล่ตอนเสียบ ESP32
   - ไม่มี COM ใหม่ = สายไม่มีดาต้า หรือยังไม่มีไดรเวอร์
   - เปิด Device Manager → Ports ถ้าขึ้น CH340 / CP210 ให้เลือกพอร์ตนั้น
4. ตั้งค่าใน Arduino IDE:
   - Board: `ESP32 Dev Module` (ถ้าชิปบนบอร์ดเขียน ESP32-S3 / C3 ให้เลือกบอร์ดนั้นแทน)
   - Upload Speed: `115200`
   - Flash Mode: `DIO`
   - Flash Frequency: `40MHz`
5. เข้าโหมดแฟลชด้วยมือ:
   - กด **BOOT ค้าง**
   - กด **EN** แล้วปล่อย EN
   - ยังค้าง BOOT อยู่ กด Upload
   - พอขึ้น `Writing` ค่อยปล่อย BOOT
6. ถ้ายังไม่ติด ลอง Upload Speed `9600` และเปลี่ยนสาย USB / ช่อง USB

ห้ามต่อคีย์แพดที่ GPIO 12 เพราะเป็นขาบูต ใช้ GPIO 32 แทน

## ปุ่มกด

- กดตัวเลข `0-9` ได้สูงสุด **6 หลักต่อชุด**
- กด `*` เพื่อล้างจอทั้งหน้า แล้วเริ่มใหม่
- กด `#` เพื่อใส่ช่องว่าง แล้วพิมพ์เลขชุดถัดไปได้
- ค่าที่พิมพ์แสดงบนจอบรรทัดล่าง และส่งออกทาง Serial Monitor

## สิ่งที่ต้องใช้

- บอร์ด ESP32 (เช่น DevKit V1)
- จอ LCD 1602 พร้อมโมดูล I2C (ขา 4 เส้น)
- คีย์แพดเมมเบรน 4 แถว × 3 คอลัมน์
- สายไฟ Dupont

## Arduino IDE

ติดตั้งบอร์ด **esp32** โดย Espressif จาก Boards Manager แล้วเลือก **ESP32 Dev Module**

ถ้าคัดลอกจากแชทแล้ว error `missing terminating " character`

## การต่อสาย

### จอ LCD 16x2 แบบ I2C

| LCD I2C | ESP32 |
|---------|-------|
| VCC     | 5V (หรือ 3.3V ตามโมดูล) |
| GND     | GND |
| SDA     | GPIO 21 |
| SCL     | GPIO 22 |

ที่อยู่ I2C ที่พบบ่อยคือ `0x27` หรือ `0x3F` โปรแกรมจะสแกนให้อัตโนมัติตอนเปิดเครื่อง

### คีย์แพด 4x3

แผงส่วนใหญ่มี 7 ขา เรียงจากซ้ายไปขวา: **R1 R2 R3 R4 C1 C2 C3**

```
  [1] [2] [3]
  [4] [5] [6]
  [7] [8] [9]
  [*] [0] [#]
```

| ขาคีย์แพด | ความหมาย | ESP32 |
|-----------|----------|-------|
| 1         | แถว 1    | GPIO 13 |
| 2         | แถว 2    | GPIO 32 |
| 3         | แถว 3    | GPIO 14 |
| 4         | แถว 4    | GPIO 27 |
| 5         | คอลัมน์ 1 | GPIO 26 |
| 6         | คอลัมน์ 2 | GPIO 25 |
| 7         | คอลัมน์ 3 | GPIO 33 |

ถ้าปุ่มขึ้นคนละตัว ให้สลับอาร์เรย์ `rowPins` / `colPins` ในไฟล์ `.ino`

## การใช้งาน

1. อัปโหลด `esp32-6digit-keypad.ino`
2. เปิด Serial Monitor ที่ 115200
3. จอจะขึ้น `Enter number` บรรทัดล่างว่างไว้ก่อน
4. กดตัวเลขได้ไม่เกิน 6 ตัว เช่น `250823`
5. กด `#` เพื่อใส่ช่องว่าง แล้วพิมพ์เลขชุดถัดไป เช่น `250823 17`
6. กด `*` เพื่อล้างจอทั้งหน้า

ข้อความใน Serial:

```
KEY 2
VALUE 2
KEY #
SPACE 250823 
KEY 1
VALUE 250823 1
KEY *
CLEAR
```

## แก้ปัญหาเบื้องต้น

- **จอไม่ติด / มีแต่กล่อง**: หมุนวอลลุ่มด้านหลังโมดูล I2C และดูผล `Scanning I2C...` ใน Serial
- **ไม่เจอ I2C**: ตรวจ VCC/GND/SDA/SCL และลองสลับ 5V กับ 3.3V
- **กดปุ่มแล้วขึ้นผิดตัว**: สลับขาแถว/คอลัมน์ตามตารางด้านบน
- **กดหลักที่ 7 ไม่รับ**: กด `#` เพื่อเว้นวรรค แล้วพิมพ์ชุดใหม่ได้
- **กด `*`**: ล้างจอทั้งหมด
